# PgHelix brand

Source: PgHelix Brand Guidelines v1.0 (identity system). Logo geometry rebuilt as SVG from the guideline's construction grid (64 x 64 units; mark at x 11.5-52.5, y 8-56; stem 9 u; wordmark in Arial Bold 44 u, converted to outlines, 16 u gap).

## Logo files (`logo/`)
| File | Use |
|---|---|
| `logo-horizontal.svg/.png` | Primary logo, light backgrounds |
| `logo-horizontal-dark-bg.svg/.png` | Primary logo, dark backgrounds |
| `logo-horizontal-single-colour.svg` | One-colour (Deep Teal) |
| `logo-horizontal-black.svg`, `-white.svg` | Solid black / solid white |
| `symbol.svg/.png`, `symbol-dark-bg.svg`, `symbol-black.svg`, `symbol-white.svg` | Symbol only |
| `avatar.svg/.png` | 512 px square for GitHub org / social avatars |

Not yet produced: stacked, compact, wordmark-only and tagline lockups, and the small-symbol cut (stem 11 u, gap 4 u) for sizes <= 48 px. Minimums: horizontal logo 96 px wide digital; symbol 24 px.

## Colour
| Name | Hex | Use |
|---|---|---|
| Deep Ink | `#0A1A24` | Primary dark / text on light |
| Graphite | `#1F2D38` | Secondary dark surface |
| Helix Teal | `#0D9488` | Accent on light |
| Signal Teal | `#2DD4BF` | Accent on dark |
| Deep Teal | `#0B6E69` | Single-colour logo, accessible teal text |
| Paper | `#F6F8F9` | Light background |
| Mist | `#E4EBEE` | Light surfaces, borders |
| Slate | `#5B6B76` | Secondary text on light |

Do not alter, rotate, recolour outside these variants, or add rounding (ends are flat, joins mitred). Keep clear space X = 12 u (one quarter of the symbol height) on all sides.
